# React Grocery Checker

A simple grocery checklist application built with **React.js, JavaScript, HTML, and CSS**. This project was created to practice React fundamentals and frontend development.

## Features

- Add new grocery items
- Delete grocery items
- Mark items as purchased or not purchased
- Toggle purchased status using checkboxes
- Dynamically update the grocery list
- Responsive interface with custom CSS styling

## Technologies Used

- React.js
- JavaScript (ES6+)
- HTML5
- CSS3
- Vite

## React Concepts Practiced

- **Components:** Building reusable UI components
- **Props:** Passing data between components
- **useState:** Managing application state
- **Event Handling:** Responding to user interactions
- **Conditional Rendering:** Displaying purchased status
- **Array Methods:** Using `map()` and `filter()` to manage grocery items

## Getting Started

1. Clone the repository:

   ```bash
   git clone https://github.com/YOUR-USERNAME/react-grocery-checker.git
   ```

2. Navigate to the project directory:

   ```bash
   cd react-grocery-checker
   ```

3. Install dependencies:

   ```bash
   npm install
   ```

4. Start the development server:

   ```bash
   npm run dev
   ```

5. Open the local URL displayed in your terminal.

## Project Purpose

This project was developed as a frontend practice exercise to strengthen my understanding of React components, state management, props, and dynamic user interfaces.
